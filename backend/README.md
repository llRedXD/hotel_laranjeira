# Back-end

Esta camada concentrará a API do sistema, as regras de negócio e o acesso ao banco de dados.

Organização inicial:

- `src/controllers`: recebe e responde às requisições HTTP.
- `src/services`: contém as regras de negócio.
- `src/models`: representa as entidades do sistema.
- `src/routes`: define as rotas da API.
- `src/config`: reúne configurações da aplicação.
