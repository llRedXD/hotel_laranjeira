# Front-end

Esta camada reunirá as telas usadas pela recepção e pela administração do hotel.

## Tecnologias

- React + TypeScript
- Vite
- Tailwind CSS
- React Router

## Comandos

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Organização

- `src/pages`: páginas e fluxos principais.
- `src/components`: componentes visuais reutilizáveis.
- `src/services`: comunicação com a API.
- `src/styles`: estilos globais e temas.
